# 화면 와이어프레임 — M0

> 구현 전 합의용 스케치. 데스크톱 우선(≥1024px), 모바일은 단일 컬럼으로 축소한다.
> 테마: 시스템(라이트/다크), 키보드 탐색·스크린리더 라벨 필수.

## 공통

- 좌측 사이드바: 로고, 내 username, 현재 기기 표시, `대화`/`기기` 이동
- 우측 하단: 오류/알림 토스트(포커스 이동 없음, `aria-live`)
- 로딩: 스켈레톤, 파괴적 동작(기기 폐기·삭제)은 확인 대화상자

## 1. 가입 / 로그인

```
┌──────────────────────────────────────────────┐
│  OneMoments                          [테마]   │
│                                              │
│        ┌────────────────────────────┐        │
│        │   로그인   │   가입         │        │
│        │                            │        │
│        │  아이디   [______________]  │        │
│        │  비밀번호 [______________]  │        │
│        │                            │        │
│        │  [        계속        ]    │        │
│        │                            │        │
│        │  🔒 이 기기에서 키를 만듭니다│        │
│        └────────────────────────────┘        │
└──────────────────────────────────────────────┘
```

**상태**
- 가입 직후: `키 생성 중…` → 완료 후 대화 목록으로 이동(개인키는 이 브라우저에만 저장)
- 새 기기 로그인: `이 기기에서는 이전 대화를 읽을 수 없습니다` 안내 후 계속
- 오류: `아이디 또는 비밀번호가 올바르지 않습니다`(계정 존재 여부 비노출)
- 레이트리밋: `잠시 후 다시 시도하세요`

## 2. 대화 목록

```
┌─────────────┬─────────────────────────────────────────┐
│ OneMoments  │  대화                        [ + 새 대화 ] │
│ @alice      │  ┌───────────────────────────────────┐  │
│ 기기: Chrome │  │ bob                    방금        │  │
│             │  │ (미리보기는 복호화 후 표시)          │  │
│  • 대화      │  └───────────────────────────────────┘  │
│  • 기기      │  ┌───────────────────────────────────┐  │
│             │  │ carol                  10:21       │  │
│             │  │ …                                  │  │
│             │  └───────────────────────────────────┘  │
└─────────────┴─────────────────────────────────────────┘
```

**상태**
- 빈 목록: `아직 대화가 없습니다` + `사용자 이름으로 새 대화를 시작하세요`
- 새 대화 모달: username 정확 일치 검색 → 결과 카드 → `대화 시작`
- 검색 결과 없음: `일치하는 사용자가 없습니다`(부분 검색·이메일 노출 없음)

## 3. 채팅

```
┌─────────────┬─────────────────────────────────────────┐
│  • 대화      │ ← bob        안전번호 확인됨  [기기]      │
│             │                                         │
│             │  ┌──────────────────────────────┐       │
│             │  │ 안녕! 오늘 시간 괜찮아?  10:21 │       │
│             │  └──────────────────────────────┘       │
│             │            ┌──────────────────────────┐ │
│             │            │ 나: 응, 좋아  10:22  ✓✓  │ │
│             │            └──────────────────────────┘ │
│             │                                         │
│             │  bob이 입력 중…                          │
│             │                                         │
│             │  [ 메시지 입력________________ ] [전송]  │
└─────────────┴─────────────────────────────────────────┘
```

**메시지 상태**
- 전송 중 `🕘`, 전송됨 `✓`, 실패 `⚠ 다시 시도`
- 복호화 불가: 회색 버블 `이 기기에서 읽을 수 없는 메시지` (내용 추정 금지)
- 상대 오프라인: 입력창 위 `오프라인 — 전송하면 상대 접속 시 표시됩니다`
- 타이핑 인디케이터: `bob이 입력 중…` (내용은 서버에 저장하지 않음)

**경고 배너**
- 기기 키 변경: `bob의 기기 키가 변경되었습니다. 안전번호를 확인하세요.` [확인]
- 새 기기: `이 기기에서는 가입 이후 메시지만 표시됩니다` (닫기 가능)

## 4. 기기·안전번호

```
┌───────────────────────────────┬──────────────────────────────────┐
│ 기기                          │ 안전번호 — bob                    │
│                               │                                  │
│ ● Chrome (현재)               │  48213 90774 11820 55496 33108   │
│   2026-11-14 · 방금            │  77204 66351 09817 22465 81330   │
│                               │  [QR 보기]                       │
│ ○ Safari                      │                                  │
│   2026-11-13 · 2일 전 [폐기]   │  상대와 대면/음성으로 대조하세요.  │
│                               │  키가 바뀌면 이 번호도 바뀝니다.   │
└───────────────────────────────┴──────────────────────────────────┘
```

- 기기 폐기: 확인 대화상자 → 해당 기기 세션 즉시 종료
- 새 기기 추가는 그 기기에서 로그인하는 방식(MVP). QR 키 이전은 이후 과제

## 흐름

```
[가입/로그인] ──키 생성──► [대화 목록] ──검색/선택──► [채팅]
                                  │                    │
                                  └──[기기]──► [안전번호/폐기]
```

1. 가입 → 키 생성 → 대화 목록
2. 새 대화 → 상대 검색 → 대화 시작(기존 대화 재사용)
3. 메시지 전송 → 서버 저장 → 상대 온라인이면 즉시, 아니면 재접속 시 수신
4. 새 기기 로그인 → 경고 확인 → 이후 메시지부터 수신

## 접근성·반응형

- 모든 입력에 `<label>`, 아이콘 버튼에 `aria-label`
- 새 메시지는 `aria-live="polite"`로 알리되 포커스를 뺏지 않음
- 포커스 링 유지, `prefers-reduced-motion` 존중
- 모바일: 사이드바 → 상단 헤더 + 목록/대화 전환(뒤로가기)
