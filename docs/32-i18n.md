# 다국어(i18n)

## 1. 범위와 현재 상태

| 항목 | 상태 |
|---|---|
| 인프라 | **완료** — 외부 라이브러리 없이 `client/src/lib/i18n.ts` + `client/src/i18n.tsx` |
| 지원 언어 | 한국어(`ko`, 기준) · 영어(`en`) |
| 언어 전환 | **인증 화면** + **대화 목록 사이드바 하단**(로그인 후에도 전환 가능) |
| 적용 화면 | **인증 화면**, **대화 목록(사이드바)**, **새 대화**, **초대 수락**, **채팅 화면 전체**(헤더·입력창·말풍선·다이얼로그), **연락처**, **기기 관리**, **Moments**, **첨부 갤러리·위치 공유·라이트박스**, **통화 오버레이·통화 기록**, **OAuth 랜딩**, **테마·Google 계정**, **관리자 콘솔**(개요·사용자·기기·세션·decoy·가입 초대·감사 로그), **날짜·시간 표기** |
| 미적용 화면 | 서버가 만드는 오류 문구, 복호화 실패 사유(`decryptAttachmentBlob`·`failureDetail`), 검색/북마크용 `"위치 공유"` — 모두 의도적 또는 배선 대기 |

번역이 없는 문자열은 **한국어로 폴백**하고, 한국어에도 없으면 키가 그대로 노출된다(개발 중 실수 탐지용).

## 2. 구조

- `lib/i18n.ts`
  - `dictionaries: { ko, en }` — 키 집합은 **완전히 동일**해야 한다(`missingKeys()` 로 검사).
  - `translate(locale, key, vars?)` — `{name}` 변수 치환, `en` 실패 시 `ko` 폴백.
  - `detectLocale(stored, navigator.languages)` — 저장값 → 브라우저 언어 → `ko`.
- `i18n.tsx`
  - `I18nProvider` 가 `locale`/`setLocale`/`t` 를 제공하고 `<html lang>` 을 갱신한다.
  - 선택은 `localStorage["onemoments-locale"]` 에 저장, 다른 탭 변경도 `storage` 이벤트로 반영.
- `components/LanguageToggle.tsx` — 한국어/English 전환 UI.

## 3. 키 규칙

- `화면.요소` 형태: `auth.username.label`, `sidebar.newConversation`, `newChat.groupNote`, `error.unauthorized`.
- 변수는 `{name}` 형태만 지원한다: `sidebar.members` → `"{count}명"`, `newChat.removeMember` → `"{name} 제거"`.
- 오류 문구는 서버 코드(`USERNAME_TAKEN` 등)를 키로 매핑한다. 서버의 `message` 는 폴백으로만 쓴다.
- 사용자 데이터(아이디·대화 이름 등)는 번역하지 않는다.
- **한국어 값은 기존 UI 문구와 100% 동일하게 유지한다.** E2E·스크린리더 라벨이 한국어 문자열로 검증되기 때문이다
  (`i18n.test.ts` 의 "same Korean wording" 테스트가 이를 고정한다).

## 3.1 이번 확장에서 옮긴 화면

| 화면 | 파일 | 주요 키 |
|---|---|---|
| 대화 목록(사이드바) | `components/ConversationSidebar.tsx` | `sidebar.*`, `nav.*` |
| 새 대화 다이얼로그 | `components/NewConversationDialog.tsx` | `newChat.*`, `error.searchFailed` 등 |
| 대화 선택 빈 화면 | `pages/ChatPage.tsx` | `chat.empty.*` |
| 초대 수락 | `pages/InvitePage.tsx` | `invite.*` |
| 언어 전환 | `components/LanguageToggle.tsx` | `lang.*` (사이드바 하단에 배치) |

## 4. 새 화면을 번역할 때

1. `dictionaries.ko` 와 `dictionaries.en` 에 같은 키를 추가한다(테스트가 키 누락·중복을 잡는다).
2. 컴포넌트에서 `const { t } = useI18n();` 후 `t("key")` 로 바꾼다.
3. **날짜·시간**은 `lib/format.ts` 에 `locale` 을 넘긴다: `formatClock(value, locale)`, `formatListTime(value, locale)`,
   `formatDayLabel(value, locale)`, `formatRelativeTime(value, now, locale)`. 생략하면 한국어(ko-KR)로 폴백한다.

## 4.1 날짜·시간 로케일화

| 함수 | ko | en |
|---|---|---|
| `formatClock` | `오후 03:05` | `03:05 PM` |
| `formatListTime`(같은 날) | 시각 | 시각 |
| `formatListTime`(다른 날) | `3월 1일` | `Mar 1` |
| `formatDayLabel`(오늘/어제) | `오늘` / `어제` | `Today` / `Yesterday` |
| `formatDayLabel`(그 외) | `2026년 3월 1일` | `March 1, 2026` |
| `formatRelativeTime` | `방금 전`, `5분 전` | `just now`, `5 min ago` |

- 상대 시간·오늘/어제 문구는 사전 키(`time.*`)를 쓴다.
- 적용 지점: 대화 목록 시간, 채팅 날짜 구분선, 메시지 시각, 마지막 접속, 대화 내 검색 결과 시각, 통화 기록, 저장한 메시지 시각.
- 관리자 콘솔·기기 관리·Moments 는 아직 `ko-KR` 고정이다(해당 화면 번역과 함께 정리 예정).

## 5. 한계

- 언어는 기기(브라우저) 단위이며 계정 동기화 대상이 아니다(테마와 다름).
- 문장 안에 조사/어순이 필요한 경우 현재는 문장 전체를 키로 둔다(문법 엔진 없음).
- 서버가 생성하는 문구(관리자 콘솔 감사 로그, API 오류 `message`)는 한국어 고정이다.
- 검색 인덱스는 언제나 한국어 문구("위치 공유" 등)를 쓴다 — 언어와 무관하게 동작.

## 6. 검증

| 계층 | 내용 |
|---|---|
| 클라이언트 | 로케일 감지 우선순위, 키 집합 일치(`missingKeys`), 폴백(키 노출), 변수 치환, **한국어 문구 고정 + 영어 번역 스팟 체크**, **날짜·시간 로케일(ko/en) 포맷** |
| 브라우저 E2E | `localStorage["onemoments-locale"]="en"` 로 고정 → 가입 화면·사이드바·새 대화 다이얼로그가 영어인지 확인 |
