# 로컬 별명 · 저장한 메시지(북마크)

## 1. 로컬 별명

상대 이름을 **내 화면에서만** 바꿔 부를 수 있습니다. 서버에 저장하지 않습니다.

| 항목 | 결정 |
|---|---|
| 저장 위치 | `localStorage["onemoments-aliases"]` — `{ [userId]: 별명 }` |
| 길이 | 40자(앞뒤 공백 제거, 빈 값이면 삭제) |
| 적용 범위 | 대화 헤더 제목·아바타, 사이드바 대화 목록, 검색 결과의 대화 이름 |
| 편집 | 대화 헤더의 **연필 아이콘** → 다이얼로그. 1:1 대화에서만(그룹은 제외) |
| 삭제 | 다이얼로그의 "별명 지우기", 또는 로그아웃 시 전체 삭제 |
| 동기화 | 기기 로컬. 다른 기기·상대 화면에는 보이지 않는다 |

구현: `client/src/lib/aliases.ts` (`loadAliases` / `aliasFor` / `saveAlias` / `clearAliases`
/ `subscribeAliases`). 컴포넌트는 `useSyncExternalStore(subscribeAliases, loadAliases)` 로
구독하므로, 별명을 저장하면 헤더와 목록이 같은 렌더에서 함께 갱신됩니다.

> 프라이버시: 별명은 평문 로컬 값입니다. 공용 PC 라면 로그아웃(또는 자동 잠금)으로 정리하세요.

## 2. 저장한 메시지(북마크)

중요한 메시지를 이 기기에 모아 두고 다시 열 수 있습니다.

| 항목 | 결정 |
|---|---|
| 저장 위치 | IndexedDB `onemoments-bookmarks` (없으면 메모리 폴백) |
| 레코드 | `messageId`, `conversationId`, `senderUserId`, `createdAt`, `text`(스냅샷), `savedAt` |
| 본문 | 복호화된 텍스트를 최대 2,000자 저장. 첨부 메시지는 빈 텍스트로 저장하고 목록에서 "첨부 메시지"로 표시 |
| 토글 | 메시지 액션의 **북마크 아이콘**(저장 시 채워짐) |
| 목록 | 사이드바 하단 **저장한 메시지** → 최근 저장순(최대 200건), 항목별 저장 취소 |
| 이동 | 항목을 누르면 `?anchor=<messageId>` 흐름으로 원문 로드·스크롤·하이라이트 |
| 정리 | 로그아웃 시 전체 삭제 |

### 원문이 삭제된 경우

북마크는 **저장 시점의 본문 스냅샷**입니다. 자동 삭제·전송 취소로 원문이 사라져도
목록에는 남으며, 이동을 누르면 "메시지를 찾을 수 없습니다" 안내가 뜹니다. 필요 없으면
항목의 X 로 지우세요.
