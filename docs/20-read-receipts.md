# 읽음 표시

내가 보낸 메시지에 대해 상대(또는 그룹 참여자)가 어디까지 읽었는지 표시한다.

## 1. 동작

- `conversation_reads`의 사용자별 마지막 읽음 커서를 사용한다.
- `message_reads`에 메시지별 읽은 시각을 함께 기록한다(읽은 뒤 자동 삭제 계산용).
- unread 배지와 대화의 마지막 메시지 시각은 `kind='text'` 메시지만 센다(반응/수정 제외).
- `GET /api/conversations/:id/reads`가 현재 참여자의 커서를 반환한다.
  - `readAt`은 커서 메시지의 작성 시각
- 클라이언트는 5초 간격으로 읽음 상태를 갱신한다.
- 내 메시지에만 표시한다.
  - 1:1: `읽음` / `안 읽음`
  - 그룹: `N명 읽음` / `안 읽음`

## 2. 서버

| 메서드 | 경로 | 설명 |
|---|---|---|
| GET | `/api/conversations/:id/reads` | 참여자만. `{reads:[{userId,lastReadMessageId,readAt,updatedAt}]}` |
| PUT | `/api/conversations/:id/read` | 기존 읽음 커서 갱신 |

- 읽음 커서가 메시지 작성 시각보다 크거나 같으면 읽은 것으로 판단한다.
- 그룹에서는 현재 참여자 중 읽은 인원만 센다(나간 사용자 제외).

## 3. UI

- 말풍선 하단 시간 옆에 표시: `오후 8:12 · 읽음`
- 그룹: `오후 8:12 · 2명 읽음`
- 수신 메시지에는 표시하지 않는다.

## 4. 한계

- 읽음 상태는 약 5초 지연될 수 있다(폴링).
- 읽음 시각 자체가 상대에게 노출된다.
- 메시지 순서는 `createdAt` 기준이며, 동일 시각 메시지는 함께 읽음 처리될 수 있다.
- 상대가 메시지를 열어도 클라이언트가 `PUT /read`를 보내지 못하면 갱신되지 않는다.
