# 제품 정의 — OneMoments

## 한 줄 정의

소중한 순간을 **두 사람만** 주고받는 **개인용 1:1 종단간 암호화 메신저** (웹 우선).

## 왜 만드는가

- 기존 메신저는 서버가 대화 내용을 읽을 수 있거나, 읽을 수 있는 구조를 전제로 한다.
- 개인 대화는 "서비스가 보관하는 데이터"가 아니라 "두 사람만 가진 기록"이어야 한다.
- 설치 없이 브라우저에서 바로 시작하고, 나중에 앱으로 확장한다.

## 타깃 사용자

- 1:1 대화가 중심인 개인 사용자
- 대화 내용의 프라이버시를 중요하게 여기는 사용자
- 보안 전문가는 아니지만, 안전번호 확인 같은 절차는 따라갈 수 있는 사용자

## 핵심 시나리오

1. **첫 대화**: 가입 → 브라우저에서 기기 키 생성 → 상대 검색 → 메시지 전송
2. **오프라인 수신**: 상대가 접속 중이 아니어도 서버가 암호문을 보관 → 상대가 접속하면 복호화해 표시
3. **새 기기**: 새 기기에서 로그인 → 안전번호로 상대 확인 → 이후 메시지부터 수신(과거 이력은 키 백업 전까지 없음)

## MVP 범위

| 영역 | 포함 |
|---|---|
| 계정 | username + password 가입/로그인/로그아웃, 세션 관리 |
| 기기 | 브라우저별 기기 키 생성·등록, 기기 목록/폐기 |
| 대화 | 사용자 검색, 1:1 대화 시작(중복 방지), 대화 목록 |
| 메시지 | 텍스트 E2E 암호화 전송, 실시간 수신(WebSocket), 오프라인 동기화, 멱등 재전송 |
| 이력 | 커서 페이지네이션, 이 기기에서 복호화 가능한 메시지만 표시 |
| 안전 | 안전번호(키 지문) 표시, TLS, 세션 보호, 레이트리밋 |
| 운영 | 헬스체크, 마이그레이션, 백업 절차 |

## 범위 밖 (MVP 이후)

- 그룹 대화, 파일/이미지/음성, 음성·영상 통화
- 푸시 알림, 이메일 초대, 연락처 동기화
- 서버 측 검색·분석, 서버 측 평문 백업
- 키 백업/복구, 기기 간 이력 이전
- 모바일 앱, 다국어, 테마 커스터마이징

## 성공 지표

| 지표 | 목표 |
|---|---|
| 가입 → 첫 메시지까지 | 3분 이내 |
| 온라인 메시지 전달 성공률 | 99.9% 이상 |
| 수신 측 복호화 실패율 | 0.1% 미만 |
| 서버 저장 데이터 내 평문 | 0건 (감사로 확인) |

## 확정된 결정

| 항목 | 결정 |
|---|---|
| 대화 형태 | 1:1 개인용 (그룹 제외) |
| 플랫폼 | 웹 우선 |
| 암호화 | E2E, 서버는 암호문만 저장·중계 |
| DB | PostgreSQL (외부에서 구성, 서버는 `DATABASE_URL`만 사용) |

## 결정이 필요한 항목

| 항목 | 선택지 | 권장 | 상태 |
|---|---|---|---|
| 다중 기기 | 지원 / 계정당 1기기 | **지원** (기기별 키 봉투) | 미정 |
| 계정 식별 | username만 / 이메일+인증 | username만 (MVP) | 미정 |
| 읽음 표시 | MVP 포함 / 이후 | 이후(P1) | 미정 |
| 메시지 보존 | 무기한 / TTL | 무기한, 사용자 삭제만 | 미정 |
| 배포 형태 | 셀프호스트 / SaaS | M4에서 결정 | 미정 |
| UI 톤 | 라이트 / 다크 / 시스템 | 시스템 | 미정 |
